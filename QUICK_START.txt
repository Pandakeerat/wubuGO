wubuGO 6.0

Bundled Windows build: run wubuGO.exe or install using wubuGO-6.0.1-windows-x64-setup.exe.
Bundled Linux build: run ./wubuGO (from a graphical session).
Source checkout: Python 3.10+ with Tkinter, then python -m launcher.app.

Open SETUP. Verify bundled files, choose your Steam Source 1 game, and prepare
assets. All 33 historical firearm records are included offline. Steam installs
and verifies the real game; it is not bundled here.

Use SETTINGS for game preferences, Proton path (optional on Linux), and optional
Discord Application ID. Use DOWNLOADS to track temporary and completed files.
LAUNCH uses -insecure, LAN mode and a local map. Read README before using mods.

MIGI and Bridge are Windows-only upstream tools. Native Linux injection is not
supported. In-game HUD/menu and weapon behavior are not verified by local tests.

Release binaries passed native Windows/Fedora installer and GUI checks. Source
recipes alone are not installers. Read the README and native self-test reports.
